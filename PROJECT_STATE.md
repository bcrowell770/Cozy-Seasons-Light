# Cozy Seasons Light - Project State

## Version 1.1.0

- Separate app identity: `Cozy Seasons Light`.
- Includes the animation improvements through regular Cozy Seasons 1.4.0.
- Basalt-only Pebble watchface for Pebble Time / Time Steel.
- Uses 12 even-hour scenes per season; each scene remains active for two hours.
- Keeps the existing settings and seasonal particle effects.
- Uses the newer shaped spring petals and autumn leaves without adding image resources.
- Hardware installation and visual behavior still require review on a Pebble Time 1.

## Relationship to Cozy Seasons

The regular Cozy Seasons project remains unchanged and retains all 96 hourly backgrounds. This folder is an independent light edition with its own UUID, so both editions can be installed separately.
